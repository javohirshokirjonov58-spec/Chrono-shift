# Chrono Shift — Controls & Keybindings Reference

## Default Keyboard Layout

| Key | Action | Behavior |
| :--- | :--- | :--- |
| `A` / `Arrow Left` | Run Left | Deterministic acceleration with ground/air friction |
| `D` / `Arrow Right` | Run Right | Deterministic acceleration with ground/air friction |
| `SPACE` / `W` / `Arrow Up` | Jump | Variable height (release early for short hop); 100ms Coyote Time & 100ms Buffer |
| `R` (Hold) | Rewind Time | Plays back history ring buffer in reverse |
| `Shift` (Hold) | Slow-Motion | Dials world simulation to 0.25x |
| `F` or `Q` | Time Freeze | Halts world simulation to 0.0x |
| `E` | Interact / Crate / Echo | Pick up/drop crates, toggle Echo Ghost recording |
| `Escape` or `P` | Pause Menu | Halts gameplay loop and opens pause modal |
| `F3` | Debug Overlay | Toggles telemetry, hitboxes, vectors, and ticks |

## Touch Controls
When running on touch devices (phones, tablets, touch laptops), Chrono Shift displays on-screen buttons:
- **Left / Right**: Directional movement
- **Jump (▲)**: Jump button
- **E**: Interact / Echo recording
- **REW**: Rewind hold
- **SLO**: Slow-motion hold
- **FRZ**: Time freeze toggle
